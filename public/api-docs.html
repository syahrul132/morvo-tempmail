MORVO TempMail API

Dokumentasi lengkap API MORVO TempMail Express. Buat email sementara, terima pesan, dan integrasikan ke aplikasi Anda.

Base URL https://morvo.me/api

⚡ QUICK START

  1. Daftar akun — POST /api/auth/register → dapat 3 credits gratis
  2. Login — POST /api/auth/login → dapat session cookie
  3. Buat mailbox — POST /api/mailboxes → buang 1 credit
  4. Cek pesan — GET /api/mailboxes/:id/messages → auto-refresh setiap 10 detik
  5. Upgrade Premium — POST /api/plan/upgrade → unlimited credits + API key

AUTHENTICATION

Dua cara autentikasi: session cookie (browser) atau API key (automation).

Session-based Auth (Browser)

Login via POST /api/auth/login. Session cookie otomatis disimpan. Gunakan credentials: 'same-origin' di fetch.

API Key Auth (Automation)

Gunakan header X-Api-Key: YOUR_KEY di setiap request. API key hanya tersedia untuk plan Premium (Unlimited). Generate dari dashboard setelah upgrade.

EXTERNAL API // PREMIUM ONLY

API endpoint untuk automation. Gunakan API key dari header X-Api-Key.

POST /api/external/mailbox Buat mailbox baru via API key ▶
Headers
ParameterTypeKeterangan
X-Api-KeystringAPI key Anda REQUIRED
Content-Typestringapplication/json
Body (opsional)
ParameterTypeKeterangan
localPartstringNama depan email (random jika kosong)
// Buat mailbox baru
curl -X POST https://morvo.me/api/external/mailbox \
  -H "X-Api-Key: tm_abc123..." \
  -H "Content-Type: application/json" \
  -d '{"localPart": "myinbox"}'
Response 201
{
  "mailbox": {
    "id": "mbx_a1b2c3...",
    "address": "myinbox@adzstore.my.id",
    "plan": "free"
  },
  "credits": 98
}
GET /api/external/mailbox Ambil semua mailbox milik Anda ▶
Headers
ParameterTypeKeterangan

// Ambil daftar mailbox
curl -H "X-Api-Key: tm_abc123..." \

Response 200
{
  "mailboxes": [
    { "id": "mbx_...", "address": "myinbox@adzstore.my.id", "plan": "free" }
  ]
}

USER AUTHENTICATION

Endpoint untuk registrasi, login, dan manajemen sesi.

POST /api/auth/register Daftar akun baru (+3 credits gratis) ▶
Body
ParameterTypeKeterangan
namestringNama lengkap REQUIRED
emailstringEmail valid REQUIRED
passwordstringMin 6 karakter REQUIRED
curl -X POST https://morvo.me/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Budi","email":"budi@mail.com","password":"rahasia123"}'
Response 201
{ "ok": true, "user": { "id": "usr_...", "name": "Budi", "credits": 3, "plan": "free" } }
POST /api/auth/login Login dan dapatkan session ▶
Body
ParameterTypeKeterangan
emailstringREQUIRED
passwordstringREQUIRED
curl -X POST https://morvo.me/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"budi@mail.com","password":"rahasia123"}'
Response 200
{ "ok": true, "user": { ... } }
POST /api/auth/logout Logout dan hapus session ▶ 
curl -X POST https://morvo.me/api/auth/logout -b cookies.txt
Response 200
{ "ok": true }
GET /api/auth/me Cek session aktif ▶ 
curl https://morvo.me/api/auth/me -b cookies.txt
Response 200 / 401
{ "user": { "id": "usr_...", "name": "Budi", "credits": 3, "plan": "free" } }

ACCOUNT & CREDITS

Kelola akun, credits, dan plan langganan. Semua endpoint butuh session login.

GET /api/account Info akun, mailbox, dan payments ▶
Response 200
{ "user": { ... }, "mailboxes": [...], "payments": [...] }
GET /api/credits Cek credits, plan, dan API key ▶
Response 200
{ "credits": 3, "plan": "free", "apiKey": null }
POST /api/credits/buy Beli credits (Rp 1.000/credit) ▶
Body
ParameterTypeKeterangan

  -H "Content-Type: application/json" \
  -d '{"amount": 10}' -b cookies.txt

{ "ok": true, "credits": 13 }

Body
ParameterTypeKeterangan
planstring"unlimited" REQUIRED
curl -X POST https://morvo.me/api/plan/upgrade \
  -H "Content-Type: application/json" \
  -d '{"plan":"unlimited"}' -b cookies.txt
Response 200
{ "plan": "unlimited", "credits": 9999, "apiKey": "tm_abc123..." }
